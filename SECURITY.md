# Security policy

If you find a security issue in this site or repository, please report it
privately rather than opening a public issue:

**[Report a vulnerability](https://github.com/MarkKatsDesign/threejs-portfolio/security/advisories/new)**
(Security tab → "Report a vulnerability").

Only the maintainer can see the report. I'll aim to reply within a few days.

The site is a static front end with no backend, accounts or forms, so the most
relevant reports concern its dependencies or anything that could affect visitors.
